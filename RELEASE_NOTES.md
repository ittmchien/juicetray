## What's new in v0.4.0

### 🛠 Fixed
- **macOS builds again.** The "already running" message now has a macOS dialog too, so the Mac app compiles and says so when you open a second copy.

- **Numbers show again on macOS 27.** When the system font gives no digit shapes, the strip uses its built-in font instead of leaving a blank gap.

### 🍎 macOS beta
- Bluetooth devices (AirPods left/right, headsets, mice…) work on macOS. Install through Homebrew, which builds the app on your Mac so Gatekeeper does not block it; see *Install → macOS* in the README.
- **AirPods look like AirPods.** AirPods, AirPods Pro, AirPods Max and Beats earbuds show Apple's own symbol from macOS, picked from the device name (Icon → **AirPods** for a device on another icon).
- **Real colour picker.** *Custom…* icon colours open the macOS colour panel instead of asking for a hex code.

Windows: download `juicetray-windows-x86_64.exe` below, or use **Update now** in the app.
