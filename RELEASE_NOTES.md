## What's new in v0.2.3

### 🎨 Improved
- The menu shows your version next to **Check for updates…** (for example *Check for updates… (v0.2.3)*).
- Opening Juicetray while it is already running now says so, instead of quitting silently. To start a newer copy you downloaded, quit the running one first (right-click its icon → **Quit**), or simply use **Update now**.

Download `juicetray-windows-x86_64.exe` below, or use **Update now** in the app.
